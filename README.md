# Javen Dotfiles

A lightweight terminal setup for Debian and Ubuntu servers.

## Features

- Nord-inspired Bash prompt
- Automatic coloring for ping, ip, df and free through grc
- Nord theme for bat
- Colored journalctl output through ccze
- grep highlighting
- less color preservation
- jlog and jfollow helpers

## Installation

```bash
git clone https://github.com/YOUR_NAME/javen-dotfiles.git
cd javen-dotfiles
./install.sh
source ~/.bashrc
